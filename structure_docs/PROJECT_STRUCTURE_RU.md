# Архитектура и структура проекта ManyStartActivities (Руководство для учащихся)

---

## 1. Общая картина

Приложение **ManyStartActivities** — это интерактивный учебный каталог-демонстратор, показыющий 25 различных и оригинальных способов создания стартового экрана (Splash Screen) в Android. Приложение состоит из главного экрана-каталога, модели данных, кастомных компонентов (Custom Views) и 25 независимых стартовых активностей, передающих данные о триггере перехода на общий целевой экран.

### Аналогия из реальной жизни: Интерактивный музей наук
Представьте приложение как **большой интерактивный музей**:
- **Главный вестибюль (`MainActivity`):** Стойка информации с оформленным стендом из 25 выставочных залов.
- **Табличка с информацией (кнопка Info):** Табличка возле каждого экспоната, объясняющая принцип его работы.
- **Выставочные залы (25 активностей вариантов):** 25 отдельных комнат. В каждой комнате расположен свой интерактивный экспонат (фонарик, пазл, интерактивная карта, зеркальная камера, физика частиц).
- **Выходной магазин/Финиш (`TargetActivity`):** Зал, куда вы попадаете после прохождения любого экспоната, где подтверждается финиш и указывается, какой зал вы посетили.

Код разделен на компоненты, чтобы не сваливать экспонаты в одну сплошную кучу — разделение поддерживает порядок, предотвращает сбои и позволяет легко добавлять новые залы.

## 2. Обзор папок и файлов

Исходный код проекта распределен по четким пакетам:

```text
zeev.fraiman.manystartactivities/
├── MainActivity.java            # Главный экран каталога
├── TargetActivity.java          # Общий целевой экран перехода
├── model/
│   └── SplashVariant.java       # Модель данных элемента каталога
├── adapter/
│   └── VariantAdapter.java      # Адаптер, связывающий данные с RecyclerView
├── view/
│   ├── FlashlightOverlayView.java # Кастомный View стирания слоя фонариком
│   └── ParticleSurfaceView.java   # Кастомный SurfaceView для частиц в фоновом потоке
└── variants/                    # Пакет, содержащий 25 стартовых активностей
    ├── StandardSplashActivity.java
    ├── PreloadSplashActivity.java
    ├── CameraSplashActivity.java
    └── ... (еще 22 активности)
```

### Пояснение компонентов:
1. **Activity (Активность):** Компонент Android, отображающий окно и обрабатывающий действия пользователя. В папке `variants/` содержится 25 таких экранов.
2. **Model (`SplashVariant.java`):** Класс модели данных, хранящий в памяти заголовки, описания и учебные пояснения.
3. **Adapter (`VariantAdapter.java`):** «Посредник». Получает список данных и связывает каждый элемент с карточкой в `RecyclerView`.
4. **Custom View (`view/`):** Пользовательские компоненты, отрисовываемые вручную через код `Canvas` (фонарик, физика частиц).
5. **Ресурсы (`res/`):**
   - `res/layout/`: XML-макеты интерфейса экранов и карточек.
   - `res/values/strings.xml`: Файл с англоязычными текстовыми ресурсами.
   - `res/drawable/`: Изображения и иконки (включая логотип `logo.png`).


## 4. Практический пример из проекта: Движок частиц (Вариант 21)

Проследим полный путь выполнения от начала до конца:

1. **Клик в каталоге:** Пользователь нажимает «Launch Demo» на карточке №21 в каталоге.
2. **Запуск Activity:** `MainActivity` создает Intent для запуска `ParticleSplashActivity`:
   ```java
   Intent intent = new Intent(MainActivity.this, ParticleSplashActivity.class);
   startActivity(intent);
   ```
3. **Загрузка макета:** `ParticleSplashActivity` устанавливает layout `activity_splash_particle.xml`, содержащий `ParticleSurfaceView`.
4. **Отрисовка в фоновом потоке:** `ParticleSurfaceView` запускает отдельный поток `RenderThread`, рассчитывающий движение 120 частиц на 60 FPS.
5. **Уведомление о сходимости:** Когда частицы сходятся в центре, SurfaceView уведомляет Activity через слушатель:
   ```java
   surfaceView.setOnParticlesAssembledListener(this::onParticlesConverged);
   ```
6. **Переход на финиш:** Activity переходит на `TargetActivity`:
   ```java
   TargetActivity.start(this, "21. Particle Physics Engine", "Particle Convergence Engine Completed");
   ```

## 5. Краткий словарь терминов

1. **Activity (Активность):** Отдельный экран Android-приложения с кодом и UI.
2. **Intent (Интент):** Объект сообщений для перехода между экранами и передачи данных.
3. **RecyclerView:** Компонент UI для эффективного отображения прокручиваемых списков.
4. **Adapter (Адаптер):** Компонент-связка между сырыми данными и визуальными карточками списка.
5. **Custom View:** Компонент UI, отрисовываемый программистом вручную на `Canvas`.
6. **SurfaceView:** Компонент для отрисовки графики и физики в отдельном фоновом потоке.
7. **SharedPreferences:** Механизм хранения небольших настроек и счетчиков в памяти телефона.
