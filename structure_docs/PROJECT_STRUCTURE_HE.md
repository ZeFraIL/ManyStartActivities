# מבנה וארכיטקטורה של פרויקט ManyStartActivities (מדריך לתלמידים)

---

## 1. התמונה הגדולה

אפליקציית **ManyStartActivities** היא קטלוג לימודי אינטראקטיבי המציג 25 דרכים שונות ודרמטיות לבנות מסך פתיחה (Splash Screen) באנדרואיד. האפליקציה מורכבת מכרטיסיית קטלוג ראשית, מודל נתונים, רכיבי תצוגה מותאמים אישית (Custom Views), ו-25 מסכי פתיחה עצמאיים המעבירים נתונים למסך סיום מרכזי.

### אנלוגיה מהחיים האמיתיים: מוזיאון אינטראקטיבי
חשבו על האפליקציה כמו על **מוזיאון גדול למדעי המחשב**:
- **האולם הראשי (MainActivity):** דלפק הקבלה שבו מוצג לוח מעוצב עם 25 תערוכות.
- **שלט המידע (כפתור Info):** עלד ליד כל תערוכה המסביר איך היא עובדת.
- **חדרי התערוכה (25 מסכי ה-Variants):** 25 חדרים נפרדים. בכל חדר יש מוצג חווה אחר (פנס, פאזל, מפה, מצלמה, חלקיקים).
- **חדר המתנות ביציאה (TargetActivity):** החדר שאליו מגיעים בסוף כל תערוכה, המאשר שסיימתם ומראה באיזה חדר ביקרתם.

הקוד מחולק לרכיבים נפרדים כדי שלא נצטרך לשים את כל הריהוט והמוצגים בחדר אחד בלגן — הפרדה זו שומרת על סדר, מונעת תקלות ומאפשרת להוסיף מוצג חדש בקלות.

## 2. סקירת תיקיות וקבצים

הקוד של הפרויקט מחולק לחבילות (Packages) מסודרות:

```text
zeev.fraiman.manystartactivities/
├── MainActivity.java            # המסך הראשי (הקטלוג)
├── TargetActivity.java          # מסך היעד הסופי
├── model/
│   └── SplashVariant.java       # מודל הנתונים של פריט בקטלוג
├── adapter/
│   └── VariantAdapter.java      # המתווך בין הנתונים לתצוגה ברשימה
├── view/
│   ├── FlashlightOverlayView.java # רכיב ציור מותאם לפנס
│   └── ParticleSurfaceView.java   # רכיב מנוע חלקיקים בשרשור נפרד
└── variants/                    # תיקייה המכילה 25 מסכי פתיחה נפרדים
    ├── StandardSplashActivity.java
    ├── PreloadSplashActivity.java
    ├── CameraSplashActivity.java
    └── ... (עוד 22 מסכים)
```

### הסבר על הרכיבים והתיקיות:
1. **Activity (מסך באפליקציה):** רכיב באנדרואיד המציג חלון ומטפל באינטראקציה עם המשתמש. בתיקיית `variants` יש 25 מסכים כאלו.
2. **Model (`SplashVariant.java`):** מחלקה פשוטה שאינה מציגה שום דבר על המסך, אלא רק מחזיקה נתונים בזיכרון (כותרת, תיאור, הסבר פדגוגי).
3. **Adapter (`VariantAdapter.java`):** "המתווך". הוא מקבל את רשימת הנתונים ומלביש כל פריט על כרטיסייה ויזואלית ב-RecyclerView.
4. **Custom View (`view/`):** רכיבי תצוגה מותאמים אישית שציירנו בעצמנו באמצעות קוד (כמו ציור עיגול אור של פנס או מנוע חלקיקים).
5. **תיקיית `res/` (משאבים):**
   - `res/layout/`: קובצי XML המגדירים איך המסכים והכרטיסיות נראים.
   - `res/values/strings.xml`: קובץ המרכז את כל הטקסטים של האפליקציה באנגלית.
   - `res/drawable/`: תמונות ואייקונים (כולל הלוגו `logo.png`).

## 4. דוגמה מעשית מהפרויקט: מנוע החלקיקים (Variant 21)

בואו נעקוב אחר המסלול המלא של תרחיש שימוש מקצה לקצה:

1. **לחיצה בקטלוג:** המשתמש לוחץ על כפתור "Launch Demo" בכרטיסייה מספר 21 בקטלוג.
2. **הפעלת המסך:** ה-`MainActivity` מפעילה Intent הפותח את `ParticleSplashActivity`:
   ```java
   Intent intent = new Intent(MainActivity.this, ParticleSplashActivity.class);
   startActivity(intent);
   ```
3. **טעינת הממשק:** `ParticleSplashActivity` טוענת את הלייאוט `activity_splash_particle.xml` המכיל את `ParticleSurfaceView`.
4. **ריצה בשרשור נפרד:** `ParticleSurfaceView` יוצרת שרשור רקע (`RenderThread`) המחשב מיקומים של 120 חלקיקים ומצייר אותם ב-60 פריימים בשנייה.
5. **דיווח על סיום:** כשהחלקיקים מתכנסים למרכז, ה-SurfaceView מדווח ל-Activity דרך ה-Listener:
   ```java
   surfaceView.setOnParticlesAssembledListener(this::onParticlesConverged);
   ```
6. **מעבר ליעד:** המסך מעביר את המשתמש ל-`TargetActivity`:
   ```java
   TargetActivity.start(this, "21. Particle Physics Engine", "Particle Convergence Engine Completed");
   ```

## 5. מילון מונחים קצר

1. **Activity (אקטיביטי):** מסך בודד באפליקציית אנדרואיד הכולל ממשק משתמש וקוד מפעיל.
2. **Intent (אינטנט):** אובייקט הודעה המשמש למעבר בין מסכים והעברת נתונים ביניהם.
3. **RecyclerView (ריסייקלר ויו):** רכיב תצוגה יעיל להצגת רשימות ארוכות של פריטים.
4. **Adapter (אדפטר):** מחלקה שמקשרת וממירה נתונים מגלם לכרטיסיות ויזואליות על המסך.
5. **Custom View (תצוגה מותאמת אישית):** רכיב ויזואלי שהמפתח מצייר בעצמו באמצעות קוד קנבס (`Canvas`).
6. **SurfaceView (סרเฟס ויו):** רכיב תצוגה מיוחד המאפשר לצייר גרפיקה ופיזיקה בשרשור רקע נפרד ללא העמסה על המסך הראשי.
7. **SharedPreferences (שרד פרפרנסס):** מנגנון פשוט לשמירת נתונים קטנים (כמו מספרים או טקסטים) בזיכרון הקבוע של הטלפון.
