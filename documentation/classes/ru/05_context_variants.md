# Анализ контекстных вариантов (13-18) - Русский

- **13. BreathingSplashActivity (Вариант 13):** «Спящий» пульс логотипа (`ValueAnimator`); удерживание пальца ускоряет пульс и будит приложение.
- **14. RitualSplashActivity (Вариант 14):** Доменный кулинарный ритуал — «посолить» экран мультитапом для проявления логотипа частицами.
- **15. ContextualSplashActivity (Вариант 15):** Приветствие по времени суток (`Calendar`) и дрожание логотипа при низкой батарее (<15%, `BatteryManager`).
- **16. QuoteSplashActivity (Вариант 16):** Случайная цитата Шекспира, сохранение количества просмотров и защита от повторов в `SharedPreferences`.
- **17. SlideSplashActivity (Вариант 17):** Слайдер «Slide to start» со сбросом на 0% при преждевременном отпускании.
- **18. VideoSplashActivity (Вариант 18):** Фоновое видео в бесконечной петле без звука (`VideoView` / `MediaPlayer`).
