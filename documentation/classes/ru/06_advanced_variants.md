# Анализ продвинутых вариантов (19-25) - Русский

- **19. MapSplashActivity (Вариант 19):** Зум карты с фокусировкой на Беэр-Шеву и падение пина-маркера с логотипом.
- **20. WebViewSplashActivity (Вариант 20):** Загрузка HTML5 Canvas из `assets` с мостом `@JavascriptInterface` для вызова нативного перехода.
- **21. ParticleSplashActivity (Вариант 21):** Движок 120 физических частиц в отдельном фоновом потоке `SurfaceView`.
- **22. MoodSplashActivity (Вариант 22):** Выбор настроения в Material 3 `ChipGroup`, меняющий цвет темы и передающий данные в `Intent`.
- **23. BottomSheetSplashActivity (Вариант 23):** Выдвижная шторка `BottomSheetBehavior` в `CoordinatorLayout` с анимацией подпрыгивания за 3 секунды.
- **24. CameraSplashActivity (Вариант 24):** Живая трансляция с фронтальной камеры CameraX с маской логотипа и дисклеймером приватности.
- **25. CalendarSplashActivity (Вариант 25):** Выделенный `CalendarView`, подсчет дней непрерывного входа в `SharedPreferences` и вращение часов.
