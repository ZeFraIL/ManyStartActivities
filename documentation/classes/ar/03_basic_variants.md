# تحليل الأنماط الأساسية (1-6) - العربية

- **1. StandardSplashActivity (النمط 1):** النمط التقليدي لتكبير الشعار مع زر متابعة ومؤقت تلقائي لـ 7 ثوانٍ.
- **2. PreloadSplashActivity (النمط 2):** محاكاة مهام التحميل بـ `LinearProgressIndicator` وتحديث النصوص.
- **3. OnboardingSplashActivity (النمط 3):** شريط تعليمي مكون من 3 شرائح بـ `ViewPager2` ومؤشر نقاط.
- **4. InteractiveSplashActivity (النمط 4):** الدخول التفاعلي بالسحب للأعلى أو 3 نقرات على الشعار.
- **5. MotionSplashActivity (النمط 5):** رسوم متحركة متتالية لعناصر متعددة بـ `AnimatorSet`.
- **6. SystemSplashActivity (النمط 6):** المعيار الرسمي لأندرويد 12+ (`androidx.core:core-splashscreen`).
