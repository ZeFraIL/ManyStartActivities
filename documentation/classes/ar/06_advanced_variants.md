# تحليل الأنماط المتقدمة (19-25) - العربية

- **19. MapSplashActivity (النمط 19):** تكبير خريطة بئر السبع وإسقاط دبوس الشعار.
- **20. WebViewSplashActivity (النمط 20):** تحميل HTML5 Canvas من `assets` مع جسر `@JavascriptInterface`.
- **21. ParticleSplashActivity (النمط 21):** محرك 120 جسيماً في خيط خلفي مستقل عبر `SurfaceView`.
- **22. MoodSplashActivity (النمط 22):** اختيار المزاج بـ Material 3 `ChipGroup` وتغيير السمة ونقل البيانات.
- **23. BottomSheetSplashActivity (النمط 23):** لوحة سفيلة ناعمة بـ `BottomSheetBehavior` مع حركة قفز تنبيهية.
- **24. CameraSplashActivity (النمط 24):** بث الكاميرا الأمامية عبر CameraX مع قناع وإشعار الخصوصية.
- **25. CalendarSplashActivity (النمط 25):** تقويم محدد (`CalendarView`) وحساب الأيام المتتالية بـ `SharedPreferences`.
